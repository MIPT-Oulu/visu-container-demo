The current model uses all 11 viable clinical features. However, the study of Chicco & Jurman suggests that the best features for estimating heart failure are serum creatinine and ejection fraction. Importantly, the same conclusion can be drawn from the vertical summary plot above. We can finally test if using only these two features would yield acceptable results. After all, the method would be easier to use if fewer measurements or less information need to be gathered from the patient. A model with fewer features has also a lower chance of overfitting.
